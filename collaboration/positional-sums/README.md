# 多目标位矩阵的整题构造

仅用官方初始值和目标值，把同题的所有目标展开为有符号数位。把每个目标看成一行，比较普通分行求和与全矩阵共享中间值，最后编译到 48 个寄存器。四道开发题上，共享使完整程序合计从 2,189 条降至 2,015 条，现有独立程序只需 1,122 条。四道留出题保留给其他方法。[逐题结果和父本版本](result.json)

| 题号 | 普通构造 | 全矩阵共享 | 共享方案最小图 | 现有独立程序 | 当时公开辅助程序 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 0493 | 485 | 462 | 431 | 254 | 228 |
| 0269 | 580 | 524 | 476 | 299 | 272 |
| 0163 | 532 | 478 | 450 | 273 | 245 |
| 0255 | 592 | 551 | 489 | 296 | 271 |

选题时，在目标数至少 15、冻结公开程序至少 150 条的题中，按独立与公开辅助程序的长度差降序选取，平局按题号降序打破。前四题为开发题，随后四题为预留的 0780、0612、0610、0470。选题使用提交 `248894967985e4e6a68ec188d8387b9f43056f9b` 的程序长度。表中的两个强基线取自较新的 `595401bd916c41dcbf060f9f5681057694d4f6ec`。生成器的输入仅含官方题目，比较器最后才读取基线程序。

普通构造为每题尝试 11 种基数的普通与平衡展开，以及 10 种宽度的二进制非相邻形式，共 32 种。共享构造对相同展开尝试两种系数处理方式，共 64 种。一种直接保留每个带权数位，另一种先将绝对系数相同的位分组再乘一次。接着跨目标寻找反复出现的有符号数值对，合并成能被多个目标使用的中间加减法。所有派生值均为界内正整数，记录每个变体的数值图，并对有望超过本组当前最短物理长度的图尝试调度。

表中“最小图”是当前已生成变体在删除无用途径后的最小算术图，寄存器调度可因重算而增加指令。它与同时记录的最短物理程序可能来自不同变体。这四题中最小图也比现有独立程序长，因此停止扩大该路线。

从此目录复跑时，下列示例假定结果暂存在同一目录下的 `pilot`。将 `/path/to/puzzles.csv` 换成已下载的官方文件，生成程序可自选输出位置。比较器会用项目的两个解释器检查全部八份生成的程序，并从 Git 读取冻结对照。一次复核的结果位于本目录 `result.json`。

```sh
python -B synthesize.py /path/to/puzzles.csv pilot 0493 0269 0163 0255
python -B check_results.py /path/to/puzzles.csv pilot --output repeat.json
```
