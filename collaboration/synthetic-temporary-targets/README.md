# 从当前算式中构造一个暂时需要的新整数

在每题自己的程序中寻找能通过一步运算得到的新值，并要求它至少可替换两条现有算式的一个操作数。比较普通搜索、接入优先选择的算式后搜索、临时强制生成同一个值再解除要求，以及强制生成一个随机备选值。每组都做两轮各 180 次的搜索，最后重放真实寄存器程序。[预算与选题](design.json) · [冻结的新整数和算式](selection.json.gz)

独立路线在 12 道开发题省 3 条，在 24 道留出题省 6 条。第 697 题的独立解也将公开辅助候选从 101 条降到 99 条。公开辅助组的 36 道试验均无直接缩短。独立留出组中，3 道题的优先方案胜过普通搜索。[开发结果](development.json) · [留出结果](holdout.json)
