# 优化退火生成的程序

在冻结的独立 141,026 和公开辅助 134,430 条父本上，先按题长分八层。两条路线各抽 48 道新近缩短的题，比较正序和倒序执行四种局部修改时的效果。正序依次是成组改写、中间值替换、带余因数分解和有成本的算式组合；倒序使用相反次序。每种次序只接受经过整题解释器检查的严格改进，一轮下来没有缩短即停。
