# 从有符号数位向量合成多目标程序

从题目给出的寄存器开始构造单位值和进制位权。把目标按数值排成小块，把整块目标上有相同数位向量的位置先合并。再对每一行按数位大小累加正桶和负桶，计算两个桶和的差。算法可自行产生所有中间值。逐目标对照共用相同的数位编码、位权构造和寄存器编译器。

在冻结独立父本 140727 的 32 道题中，384 次构造全部通过完整题目重放。直接构造取 3 种进制的逐题最短程序，32 题合计 12218 条。分桶构造可在 3 种进制、3 种块大小中选择，合计 11079 条，有 22 题较短、1 题相同、9 题较长。固定块大小为 2 后，两组每题各比较三套参数，分桶组仍省 1121 条。块大小 3 和 4 分别省 655 和 489 条。

原父本在这 32 题合计 4604 条。分桶结果逐题至少多用 23 条指令，没有得到新上界。两组各自最佳程序均重新构造并核对指令指纹，又与未抽样的 968 题合并，由第二个解释器作完整重放。

从仓库根目录运行下列命令即可复现两组实验。参赛者需自行取得官方题面。加上 `--output` 可指定结果目录。

```text
python -B collaboration/pippenger-buckets/run.py --puzzles data/puzzles.csv --phase development
python -B collaboration/pippenger-buckets/run.py --puzzles data/puzzles.csv --phase holdout
```

`design.json` 保存固定选题和参数。`observations.json.gz` 包含每一配置的指令数、图大小、同列合并次数及程序指纹。`result.json` 汇总开发集、留出集、等配置数量对照和第二解释器回放。
