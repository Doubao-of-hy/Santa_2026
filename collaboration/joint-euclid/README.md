## 双目标欧几里得链

同时删除两个高成本的官方目标，在整数对上向后搜索。从 `(A,B)` 转到 `(B,|A−kB|)`，下一步可更换被减数、系数和符号。保留图中已有的值可以直接使用，也可以用一次合法运算合成所需常数。反向链的两个末值必须能从其余程序构成。对照只允许一轮，实验最多八轮，两者共用相同的终止规则、初始目标对和寄存器调度。

植入题从 7 和 11 开始，依次相加产生 18、29、47、76、123、199，第五、第六个值是目标。在计分题中，两组各检查 144 对，分别展开 12,360 和 12,386 个状态，没有一对能在规定的终止词典中同时落地。实验随后转向内部已有结构的第二种构造。[冻结设计](./design.json) · [植入题指令](./outcomes/positive.json) · [开发记录](./outcomes/development.json) · [留出记录](./outcomes/holdout.json)

## 共享尺度和截距

从父程序中挑选分别只服务两个不同官方目标的私有节点。对其值 `u < v`，令 `u = kh + e` 和 `v = lh + e`。枚举候选已付费系数 `k < l`，利用差分 `v−u = (l−k)h` 恢复正整数尺度 `h` 和有符号截距 `e`。接着删除两根，检查构造两根所需的常数、乘积与加减法能否一起放回父程序。对照允许一条一条地接受严格变短的单根改写，实验还允许两根同时替换。

在植入题中，两个共享的新值为 `70,747 = 263 × 269` 与 `68 = 31 + 37`。两个目标分别等于尺度乘 3 或 5，再加 68。各分支单独重新构造只能和原有四步打平，同时重新构造才从八步省至六步。[植入题的逐条程序与共同常数](../shared-intercept/outcomes/positive.json)

在真实的 13,615 个跨分支节点对中，代数筛选找到 87 个尺度与截距组合。删除两根并重算可用值后只剩八个构造，分布在三题。第 986 题得到的最小图为 173 条，父本 170 条。第 838 题为 140 对 139，第 3 题为 196 对 196。三题都没有短于父本的图，因此未扩大到其他题。[冻结设计](../shared-intercept/design.json) · [开发记录](../shared-intercept/outcomes/development.json) · [留出记录](../shared-intercept/outcomes/holdout.json)

已有的 `collaboration/positional-sums` 对整题使用固定基数展开及跨行公共子表达式，`collaboration/shared-quotients` 和 `rational_links.py` 逐目标搜索商与偏移。`paired_outputs.py` 搜索两个输出各用同一对整数做一次运算。`creative_hcub.cpp` 已实现受多常数乘法启发的共享成本估价。本次额外检查的是可多次交换两根的商链，以及从两个独立私有根的差分恢复两份同时付费的中间数。候选只使用同题的冻结父程序及官方起始值。作者为 Hansen0223/Santa_2026 项目 Codex；父程序归属在 `aca4989:public-assisted/origins.csv` 中逐题保存。

## 复验

在完整 Git 克隆中准备 Python 3.12 或更新版本、NumPy 及比赛原版 `puzzles.csv`。从本目录执行以下命令。脚本读取固定提交的程序及作者表并校验文件指纹，使用仓库两套解释器重放各题完整父程序、实际变短程序及植入题。输出只写到指定目录。

```sh
python -B experiment.py --puzzles /path/to/puzzles.csv --output recovered/euclid
python -B ../shared-intercept/experiment.py --puzzles /path/to/puzzles.csv --output recovered/intercept
```

在仓库之外保存本目录时，通过 `--repo /path/to/Santa_2026` 指定克隆。只复验植入题可添加 `--phase toy`。记录中的运行时间随机器变化。
