# 两个公开版本能否重组出更短程序

Asterios 第 113 版相对暂停时公开辅助父本缩短了 354 题。从这些题中按新程序长度分八层，每层用固定哈希顺序选 6 道开发题、6 道留出题。对两组各 48 道题，分别合并两份程序已有的算式、再加入最多 24 个候选辅助值、或增加从父程序反推出的算式。每种方法每题限时 0.65 秒，用实际寄存器程序作比较。96 道题共 288 次搜索，均未进一步缩短，因此停止其余 258 题的扩展。

三个输入依次为暂停版本的公开辅助程序、逐题接入第 113 版时的候选、开始本试验时的 134,487 条候选。每个文件的哈希、题号、求解器状态和每题的实际长度见记录。限时内没有找到更短程序的题仍可能有更短解。[试验设计及按组汇总](controls.json) · [全部逐题结果](rows.json.gz) · [第 113 版来源](../evidence/release-v113.json)
