# 完整目标祖先的双父本替换

在独立候选 140,811 条中冻结 32 道开发题、32 道留出题。每题的第二份程序也仅由官方初值求得，64 份第二父本随 `guides.csv.gz` 保存。

沿两个方向把一个目标依赖的整组运算换到另外一个父本。按代价选择目标与随机选择目标共生成 6,888 个中间程序，逐个分配寄存器并用两种解释器检查。两种顺序分别经过 1,329 和 1,555 个比两个父本都长的状态。原 Wang 交叉使用相同父本，按相同尝试次数运行 3,444 轮。三种办法在开发和留出组的收益都是零，结束扩大测试。[预登记](design.json) · [完整回执](result.json)

在仓库根目录执行以下命令可重跑第 680 题。提供官方题库，并在 PATH 中加入 g++，或用 `--compiler` 指定其完整路径。

```text
python -B collaboration/target-relink/replay.py --repo . --puzzles data/puzzles.csv --id scored_0680
```
