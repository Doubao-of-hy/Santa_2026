# 在主库自己的父本上跑 Wang 退火 · 两题共省 3 条

本实验的父本是仓库在提交 [62e194b](https://github.com/Hansen0223/Santa_2026/tree/62e194b3541cad7e28cd58e4fa3551e9455dd806) 时的
`public-assisted/submission.csv`（**134,063** 条，SHA-256 为 `49d1ac9e9c8e9435e18c516e1748cad13022ee3148596cf245fc53adbd859d8b`），
用仓库内 Wang Jakie 的退火程序逐题搜索，并保留每道题较短的程序。[退火程序](../../generative/wang/anneal.cpp) · [作者和许可](../../generative/wang/NOTICE.md)

## 复现

```bash
g++ -O3 -std=c++20 -static generative/wang/anneal.cpp -o /tmp/anneal

python -B collaboration/anneal-current-parent/reproduce.py \
    --puzzles data/puzzles.csv --binary-dir /tmp --rounds 35 --jobs 2
# 200 轮同样只得到这两行：python -B ... --rounds 200
```

请在包含上述历史提交的 Git 仓库中运行，并将比赛的 `puzzles.csv` 放在命令指定的位置。脚本会自动读取固定版本的父本。如果另有该文件的副本，可用 `--base` 指定，脚本会先核对文件哈希。

复现时会回放全部 1,000 题，并核对两份实验记录中的题号、完整程序、逐题长度和哈希。遇到缺失或额外的改动，脚本会报告失败。

耗时参考：1,000 题 × 35 轮约 2.5 分钟，× 200 轮约 10 分钟（2 核）。
