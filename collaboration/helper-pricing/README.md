# 用松弛模型给新增中间数排序

预登记的 24 道题分别使用独立和公开辅助父程序。三种方法一共做了 144 次整数选择，所有模型都在给定的算式集合内达到最优，真实题没有缩短。两目标植入样例从 6 条缩短到 3 条，结构计数和松弛筛选都找到了共享乘积。这个结果只涉及这里的候选集合。[分组及规则](design.md) · [逐题候选、选择及松弛变化](rows.json.gz)

| 父本及组别 | 符合生成与复用条件的新数 | 实际求过松弛的新数 | 降低松弛值的新数 | 两种排序的前四项集合不同的题数 |
| --- | ---: | ---: | ---: | ---: |
| 独立开发 | 911 | 134 | 3 | 2 |
| 独立留出 | 1,801 | 273 | 3 | 2 |
| 公开辅助开发 | 814 | 137 | 2 | 1 |
| 公开辅助留出 | 1,344 | 276 | 5 | 1 |

每题从父本取得已有数值，保留符合先后次序的至多八个已知算式。每个候选中间数最多保留四种生成办法，为每个已有数最多增加两种用法。分别比较原有数、基于独享路径计数选出的四个新数，以及按松弛目标下降量选出的四个新数。每个整数解都按实际寄存器编译和重放。连续解的目标值只解释这个有限模型。该方法在留出组的整题收益为零，结束扩展。

提供比赛题库以及 Python、SciPy 和 OR-Tools，可从根目录执行以下命令；将 `development` 换为 `holdout` 或 `synthetic` 可重跑另两组。

```text
python -B collaboration/helper-pricing/search.py --repo . --puzzles data/puzzles.csv --out work/pricing --group development
```

从 290 道历史独立改进题学习哪些新整数常出现于较短的程序；另用 90 道题评估，其中 81 道能枚举出这样的整数。按结构排序能在前 12 个候选命中 67 道，学习排序命中 61 道。在另一组 56 道题上，两种排序都未缩短独立和公开辅助程序，本轮结束。[训练及求解程序](learned.py) · [题号、模型与逐题结果](learned-results.json.gz)
