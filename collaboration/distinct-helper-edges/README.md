## 为什么可以减少配对数

设原题有 m 个不在起始值中的不同目标。每个目标第一次出现至少占用一条指令；生成这些目标以外的不同中间值再占用指令。沿用仓库的前缀证明：先用原始关联计数证明至少需要 k 个不同辅助值，才允许把能够用前 k 个辅助值取得的整个整数域 A 免费送给程序。这个域包括可以穿插生成的目标。已存实现对每个 k 的所有合法前缀取上包络；若超出 3,500 个值，就停止使用该深度。程序只使用实际产生的深度，且 k 不超过已有独立辅助值下界和 4。

设 B = A ∪ 全部目标，并删除能从 B 的两个操作数一步生成的待求目标。对其余目标 S，按首次产生时的两个操作数分类。只用一个新辅助值及 B 中一个值，或两次使用同一新辅助值，仍由仓库原有的单点容量计数。对两个不同新辅助值的情形，把实际负责生成目标的无序辅助值对画成边。每条使用的边上任选一个它首次生成的目标作为标记。每个目标只取首次生成的那次，因此所有边的标记彼此不同。一条边还能首次生成其他目标，额外的贡献继续用原先逐边、逐顶点的容量计数。

若任何四个不同、在 B 之外的整数都不能用六个不同的 S 中目标标记它们的六条边，则这张代表边图没有四点完全图。它在 h 个辅助值上至多有 ⌊h²/3⌋ 条边。一个直接证明是删去任意一个三角形：外部每个顶点至多连到这个三角形的两个顶点，删去的边至多 2h−3，由归纳得到 h²/3。若没有三角形，每条边的两端度数之和至多 h，对所有边求和并应用平方和不等式，得到边数至多 h²/4。取整后，将计数中的简单配对上限替换成 min(C(h,2),⌊h²/3⌋)。多目标同边的额外容量继续保留。某个 h 的总覆盖仍小于 |S| 时，h 个新辅助值不足；取第一个可能足够的 h，即得总指令下界 m+k+h。

## 两种独立验证

**闭合三角形。** 给定目标 t 和相邻整数 a，另一个操作数属于 t−a、a−t、a+t、t/a、a/t、t×a。把这六种变换写成 Möbius 矩阵。取三个不同标记，按标记大小给无向三角形的三条边指定位置。三角形总能重新命名顶点以符合此顺序。穷举 216 种变换组合，精确解闭环的不动点。分母为零的代入会被拒绝，整数除法必须整除，逐个顶点需在 [1,题目上限] 内、相互不同且不属于 B。对每个合法三角形，穷尽第四个顶点及三条新边上的剩余标记，检查能否选出三个彼此不同的标记。[闭环实现](cliques.py)

**按辅助值排序。** 令四个值满足 u < v < w < d。从最小值 u 出发，到较大邻居的一条边只能使用 t−u、t+u、t/u 或 t×u。枚举两个邻居，将它们表示为关于 u 的 Laurent 多项式，检查其和、正差、积和整数比能否产生第三个标签。清去 u 的负幂后，非零方程至多为二次。再从 u 的全部较大邻居中直接枚举 d，独立检查另外两条边和六个标记。这份实现使用独立的方程构造、求根、第四点枚举和标记匹配。[排序实现](sorted_quads.py)

所有系数、矩阵乘积、判别式及整数平方根均使用 Python 任意精度整数；题目本身的运算结果受原题整数上限约束。遇到恒等方程，两份实现仅在题目上限不超过 128 时枚举所有可能起始整数。更大上限若仍有未决恒等族，返回 UNKNOWN；只有两者都给出 ABSENT 才使用较强的边数上限。能够给出具体完全图见证的域不获额外下界。每份正式证书的普通容量亦重新与仓库 `domain_bounds.missing_capacity` 的结果比较。

两套程序共与 438 个独立直接四元组穷举结果核对，其中 229 个有这种完全图，209 个没有，352 个触发过恒等族。另有一组植入的六个不同标记和一次强制 UNKNOWN 的回退测试。[小整数实测](evidence/toy.json) · [开发组两套结果](evidence/screen-dual.json) · [留出组两套结果](evidence/replicate-dual.json)

## 复验

使用含固定提交的完整 Git 克隆、Python 3.12 或更新版本以及比赛原版 `puzzles.csv`。从本目录运行下列命令，将两个绝对路径换成本机位置。全量证书验证会从官方题目重算约束、域、两个整数验证器及逐题界；程序不读取匹配的搜索缓存。

```sh
python -B toy_checks.py reproduced-small.json
python -B certificates.py verify --repo /path/to/Santa_2026 --puzzles /path/to/puzzles.csv --receipt pilot-certificates.json --jobs 4
python -B certificates.py verify --repo /path/to/Santa_2026 --puzzles /path/to/puzzles.csv --receipt full-certificates.json --jobs 4
```

复现含无收益题在内的全部筛查时，先为首批执行以下两条命令，再以 `replicate` 替换 `screen` 重复执行。扩展命令默认重放 15 批，也可加 `--batch 1` 单独运行一批。

```sh
python -B screen.py --repo /path/to/Santa_2026 --puzzles /path/to/puzzles.csv --phase screen --out screen.json --jobs 4
python -B check_cases.py --repo /path/to/Santa_2026 --puzzles /path/to/puzzles.csv --screen screen.json --out screen-dual.json --independent --jobs 4
python -B extend.py --repo /path/to/Santa_2026 --puzzles /path/to/puzzles.csv --out recovered --jobs 4
```

原点集容量、额外覆盖和前缀域沿用本项目的 `lower_bounds.py`、`domain_bounds.py`。新的无完全图判据、两份独立整数实现和逐题合并验证由 Hansen0223/Santa_2026 项目 Codex 完成。
