# 双输出模约束程序综合

在固定独立父本 140727 的 32 道题上，30 道满足切除两小段私有依赖的条件。每道题只选一对根。分别使用模 5 和模 5、7、11 的 CP-SAT 筛选，在同样的 2.5 秒上限内搜索各长度。中间数由新程序自由产生，所有模数共用运算和输入位置。除法约束允许分子分母同为零时保留任意商，再以完整整数和真实寄存器检查。

两组各运行 58 个长度模板，四份全量输出独立重放均为 140727，与冻结父本逐字节相同。单模检验 99375 个不同拓扑，零个模板穷尽。三模检验 8609 个，30 个模板穷尽。两组在开发集和留出集都没有缩短完整程序。穷尽只适用于预选输入、拓扑限制和长度。人工正例将四条指令缩到三条，另外两组对照分别覆盖模零除法与同余碰撞。

`design.json` 保存预先冻结的选题、父本及预算。逐题计数和状态在 `observations.json.gz`，汇总在 `result.json`。同一台机器上按墙钟计时也会有吞吐波动。

从仓库根目录运行下列命令。依赖 Python、OR-Tools 9.15.6755 和仓库现有的寄存器编译器。复验真实题需自行取得官方题面。

```text
python -B collaboration/joint-modular/replay.py --controls
python -B collaboration/joint-modular/replay.py --repo . --puzzles data/puzzles.csv --id scored_0487
```
