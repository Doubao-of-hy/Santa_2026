# 按是否使用指定辅助数证明下界

在已有共边三角形排除证书的 622 道题上，本轮又把 47 道题的下界各提高了 1 条。前 32 题有 2 道成功，随后 64 题有 9 道，其余 526 题有 36 道。6,285 个获接受的叶子都经独立整数枚举复核。和已复验的外部证明逐题取最大后，1,000 题下界为 37,968。[逐题合并回执](../evidence/combined-membership.json)

取一个仍可能参与计算、且可用来生成许多目标的整数 x。任何候选程序要么使用 x 作为额外辅助数，要么不使用。在使用的一侧，把 x 直接授予候选程序，同时扣除一个辅助数名额。在另一侧，排除 x。只在两侧都无法产生全部目标时排除这个预算。在叶子重新枚举可产生的目标，计算单个辅助数、成对辅助数能覆盖的上限。先前排除的共边三角形在各叶上仍被排除，因为新增授予的值只会缩小需要计数的目标集、缩小可作额外辅助数的整数集。达到搜索上限的分支保留为未决。[搜索](search.py) · [从官方题目重建并逐叶验证](verify.py)

另在 120 个小整数域中直接穷举了 20,996 个辅助数组合。复核器还将快速容量计算与 600 次直接容量计算比较。举例，在仓库根目录运行以下命令可以复查首组及其小域对照。

```text
python -B collaboration/conditional-helper-membership/verify.py --puzzles data/puzzles.csv --claims collaboration/conditional-helper-membership/pilot.json --output work/pilot-verified.json
```
