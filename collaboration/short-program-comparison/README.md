# 18 道短题的单父本和双父本对照

两条独立路径逐题取短后，独立总步数从 141,441 降至 141,439。逐题合并全部可行程序后，公开辅助总步数为 135,078，起点为 135,078。两份合成都经两套解释器核对全部 1,000 题。

18 对独立对照中，单父本在 1 题更短，双父本在 1 题更短，另有 16 题等长。每题每组使用相同随机种子，各搜索 350 轮。另有一组仅使用该题的公开辅助父本。单独使用该组后，合计节省 0 步。

两组独立搜索都从独立提交的同一行开始。双父本组另外取得一个辅助值集合不同的独立程序。18 个附加父本中，15 个由独立生成器从官方输入起算，3 个来自较早的独立存档。7 题的公开辅助初始程序与单独立父本逐指令一致。

相同输入的 7 对搜索有完全相同的获胜指令、发现轮数、候选计数和最终长度。第 29 题的双父本组在第 72 轮找到 39 步程序，使用了 4 个两份父本中都没有的辅助值。第 84 题的单父本组在第 192 轮找到 43 步程序。这里的轮号从 0 起算。[逐项审计](control-audit.json)

对 14 道双父本数值并集超过 60 的题，另试了有限值域内的约束求解。在完整并集上额外加入 48 个由运算产生的候选值，并在有限预算内寻找更短程序。42 组全部达到搜索预算，未产出可行程序或最短性证明。[预登记](fallback-protocol.json) · [全部受限搜索回执](fallback-results.json)

`independent.csv` 可直接合入独立基线。`assisted_only.csv` 仅收录公开辅助生成器比其本身起点更短的程序。`assisted.csv` 汇总相对公开辅助基线最短的可行行。每个文件的 SHA-256 及逐题来源保存在 [总回执](results.json)。

从本仓库根目录运行复现程序。还需公开提交 `2e04c7ab5fab2286d509e81074ef50979b708f40` 或其后版本中的生成器、官方 `puzzles.csv`、Python 3.12 及支持 C++17 的编译器。在仓库根目录执行以下命令。`--ids` 可列多个题，省略时重放全部 18 题。逐次比较所有获胜指令和发现轮号。

```bash
python -B collaboration/short-program-comparison/replay/reproduce.py --repo . --puzzles data/puzzles.csv --temp-dir work/replay-short --ids 0029 --jobs 2
```

14 道题的两份独立父程序合起来产生超过 60 个不同的数。因此另做受限的布尔约束求解，在父本数值并集上加入最多 48 个新候选。三个来源各试 14 题，42 次均达到运行预算，未产生新的可行程序，也没有提高全题下界。[预先登记的条件和预算](fallback-protocol.json) · [42 次判定](fallback-attempts.json) · [实现](splice.py)

上述 7 道输入程序相同的对照题，两个单父本分支的算式、发现轮号和候选池计数全部一致。[一致性核查](control-audit.json)

布尔约束的复验另需 python-sat 1.9.dev24。可在仓库根目录运行 `python -B collaboration/short-program-comparison/splice.py --id 0021 --arm multi --puzzles data/puzzles.csv --output work/pool-check`。复验入口从冻结的父程序读取输入。[有限整数集的求解器](fixed_pool.py)
